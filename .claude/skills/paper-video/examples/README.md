Complete 4-minute video for Chachan, Murray-Clay & Fortney (arXiv:2608.23682).
To re-render it: copy the template into a project, then copy these over it as
`common.py`, `narration.py`, `video.py`, and set scenes.txt to:
S0Hook S1Mass S2Split S3Apps S4Disk S5Outro (one per line).
Patterns worth copying: S1Mass (bar -> histogram -> levelled average, zooming axes),
S2Split (ValueTracker probe, equation that grows a term, threshold + excess bar),
S4Disk (time-driven particle system, counting number).
